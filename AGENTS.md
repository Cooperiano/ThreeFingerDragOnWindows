# Touchpad Control source adaptation

Read README.md and NOTICE.md. Preserve upstream MIT attribution and public history.
This is an experimental source snapshot of the 2.2.0.48 adaptation based on upstream
2.0.7, not an official Microsoft Store release or an automatically updated upstream.

Do not commit credentials, signing keys, user preferences, raw HID/input logs,
screenshots, memory dumps or installed packages. Build output and the generated
MissionControl payload stay ignored. No public installer/signing pipeline.

Tests/builds are not physical touchpad acceptance. Never start an input receiver,
inject pointer input, change Windows tracking settings, modify login tasks, install
a certificate or replace a live package merely to validate source publication.
Seelen is the optional outer host; retain standalone recovery and disabled overview.
